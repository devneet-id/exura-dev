A responsive grid

Eight tiles in a flex="wrap" row; the width changes per breakpoint with prefixed size.

  • phone (< 640px): one tile per row
  • sm (≥ 640px): two per row
  • md (≥ 768px): three per row
  • lg (≥ 1024px): four per row
  • resize the window: no tile overflows or overlaps
