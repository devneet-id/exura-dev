scenario · exuraphp-mode

Switch mode: development & production

Exura::configure(['mode' => …]) rebases the settings of exuraphp. development (the default) answers with the trace "E X U R A - …" — route, method, notices, time — and full errors (file, line). production answers without the trace and without paths: a 500 says only Internal Server Error. The same routes run in api/ (development) and api/production/.
