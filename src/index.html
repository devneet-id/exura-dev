Exura playground

The workbench of the series. Every page loads the Exura files of /vessel/ — fetch them with php exura.

exuracss

  • Components — button, card, form, list, table
  • Layout — container, flex, size, misc
  • Text & ring
  • Color balancing — shades 1–10
  • Clip — emoji icons

exurajs

  • Module, state & effect
  • Template — escaped and raw
  • Store
  • Watch — lazy on viewport
  • Router

exuraphp

  • GET /api/hello
  • GET /api/echo?name=exura
  • GET /api/user/42 — wildcard
  • GET /api/notes
  • GET /api/fail — error as JSON
  • GET /api/nowhere — fallback 404
  • Request console (any method, any body)

apps — the three together

  • Notes — exuracss + exurajs + exuraphp
