Template

The content of <exura-name> is the template. Double braces escape the value, triple braces insert raw HTML — in text and in attributes.

Escaped and raw

Type HTML below: the left side shows it as text, the right side renders it.

escaped
{{html}}
raw
{{{html}}}

hover me — the title attribute is escaped too

 
<div>{{html}}</div>      escaped
<div>{{{html}}}</div>     raw
<a title="{{html}}">      escaped in an attribute

Swap the template

render(newTemplate) replaces the template, then renders it with the same data.

Template A · {{name}}

 
swap.render('<p>Template B · {{name}}</p>');
