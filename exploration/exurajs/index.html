Module, state & effect

A module owns its state. state.set() runs every effect whose dependencies changed; render() fills the module's template.

Counter

One effect re-renders when count changes.

count
{{count}}
 
Exura.module(function counter() {
  const { state, effect, render } = counter;
  state.set('count', 0);
  effect(() => render(), ['count']);
});
counter();

Effects with and without deps

An effect without deps runs on every change; one with ['a'] only when a changes. Setting the same value runs nothing — watch the log.
