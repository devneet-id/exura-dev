exuracss

Components

Buttons, cards, forms, lists and tables — each styled by one attribute whose value reads like a sentence.

button

A color, and optionally a size: sm, lg. Works on <a> too.

a[button] 
<button button="primary">Save</button>
<button button="primary lg">Save</button>
<a href="#" button="secondary">Link</a>

card

A solid color, or a tint NAME:1–NAME:10 that blends with the page. All tints side by side: Color balancing.

card="primary"
card="secondary"
card="light lg"
card="dark sm"
card="primary:2" + ring
card="default:1"
<div card="primary">…</div>
<div card="primary:2" ring="b:full b:primary-5">…</div>

form

Inputs, selects and textareas are styled without attributes.

list

Lines between items (ring:y, with a color), or items in a row (dir:x).

  • first
  • second
  • third
  • first
  • second
  • third
<ul list="ring:y ring:default-3">…</ul>
<ul list="dir:x">…</ul>

table

Lines: ring, ring:x, ring:y, with a color such as ring:primary-5.
